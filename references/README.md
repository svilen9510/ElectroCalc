# Engineering references

The `references/private/` directory is reserved for local private engineering and standards documents used for research and verification. Its contents are intentionally excluded from Git.

Licensed standards and manufacturer PDFs must not be committed to this repository. Project code and trackable documentation should contain only concise source metadata, citations and references, derived engineering facts, and formulas where appropriate. Substantial copyrighted source text and complete copyrighted tables must not be reproduced in the repository.

Intended source groups include:

- IEC
- Schneider Electric
- ABB
- Eaton
- Siemens

These groups describe the intended organization and do not imply that documents from every source are currently available locally.
